# Security policy

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/Vojow/genea/security/advisories/new) for security problems in genea. Select **Report a vulnerability** from the repository's Security advisories page.

Do not disclose vulnerabilities, credentials, private records or database contents in public issues or pull requests. If the private form is unavailable, do not use a public issue as a fallback for sensitive details.

Include the affected version or commit, a description of the impact, reproduction steps and a minimal synthetic example where possible. Remove real family data, browser sessions, API keys and recovery material from examples and logs.

## Scope and coordination

Genea is experimental software. Reports concerning the current default branch are welcome; there is no separate promise of long-term support for older versions. The maintainer will coordinate triage and any fix within the private GitHub report. Please coordinate public disclosure after a fix or mitigation has been discussed.

This policy does not ask researchers to upload genealogy collections or live personal data to demonstrate an issue.
