# Third-party dependencies and assets

The MIT license in this repository applies to the genea project code and documentation provided under that license. Third-party dependencies retain their own licenses and notices; the project license does not replace them.

Python and JavaScript dependency versions are recorded in pyproject.toml, uv.lock, package.json and package-lock.json. Dependencies are installed separately. This source package does not bundle their installed environments, generated dependency bundles or map tile datasets. Preserve the relevant third-party notices when distributing a build that includes dependencies.

Historical records, genealogy databases, archive reproductions and private research materials are not included in this source repository and are not licensed by the project's MIT file.

The initial publication review inventories dependency metadata; it is not a complete legal audit of every optional dependency or future generated asset. Any later bundled font, image, tile or document requires its own provenance and permitted-use review.
